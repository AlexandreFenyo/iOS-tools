只需一部 iPhone，10 分钟内找出家中的 Wi-Fi 信号死角。
在各个房间之间走动，轻点即可测量，一张反映真实 Wi-Fi 性能的彩色地图会自动生成——就在你真正生活的地方，测出速度与延迟。
无订阅。无广告。无需账户。一次购买，永久拥有。

你能真正了解到什么
- 哪些房间网速慢、慢多少，用可以据此采取行动的数字说话
- 问题出在 Wi-Fi 上，还是出在宽带线路上
- Mesh 节点、扩展器乃至路由器本身应该放在哪里
- 网络中哪台设备在占用你的带宽
- 网络中每台物联网设备都在对外广播哪些关于自己的信息

使用方法
1. 从现成的户型图中选择一张，或使用你自己的户型图照片
2. 走到某个位置，轻点一下——应用会测量该处的吞吐量和延迟
3. 在每个房间重复操作，热力图随之逐步生成
4. 将完成的地图保存到照片，挪动路由器后再对比

分步模式会替你完成设置：无需选择目标，无需配置协议，也无需阅读文档。想要完全掌控时，高级界面依然可用。

无需额外硬件。无需订阅。
专业的 Wi-Fi 勘测需要 Ekahau Sidekick 或 WLAN Pi。这款应用只需要你的 iPhone。而且与 App Store 上几乎所有 Wi-Fi 分析应用不同，它没有周订阅、没有年订阅，也没有广告——一次买断。

同时也是一套完整的网络工具箱
- 扫描局域网中的所有设备，显示厂商、IP 地址和开放端口
- 发现所有 mDNS/Bonjour 服务：HomePod、Apple TV、打印机、物联网设备
- 对本地设备及任意互联网主机进行 Ping 和延迟测量
- 以另一台运行本应用的设备、任意 TCP CHARGEN/DISCARD 服务器或互联网为对象测量吞吐量
- 在你自己的设备上运行 TCP CHARGEN 或 DISCARD 服务
- 以 3D 动画呈现本地网络拓扑

内置完整的 SNMP 客户端
查询路由器、交换机、接入点和打印机上的任意 SNMP 代理。支持 SNMP v1、v2c 和 v3，支持 noAuthNoPriv、authNoPriv 和 authPriv，MD5 与 SHA1 认证，DES 与 AES 加密。内置 64 个标准 MIB，对象标识符可离线解析为易读的名称——无需服务器，无需订阅，除了代理地址和凭据之外无需任何配置。

家庭适用，专业人士同样适用
由网络工程师打造。简单到周日下午就能诊断你家的网络，精确到电信专业人士也在工作中使用。

购买前须知：本应用不能做什么
Apple 不允许任何第三方 iOS 应用读取 Wi-Fi 信号强度或扫描周边网络，App Store 上没有任何应用能做到——这正是专业工具需要外接硬件的原因。本应用绘制的是它在你所站位置能够测量到的数据：真实的吞吐量和延迟。这正是家庭热力图所需要的。它测量的是你当前连接的网络，每次生成一张热力图。
