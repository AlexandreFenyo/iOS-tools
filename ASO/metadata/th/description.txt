ค้นหาจุดอับสัญญาณ Wi-Fi ในบ้านได้ภายในไม่ถึง 10 นาที ด้วย iPhone เพียงเครื่องเดียว
เดินจากห้องหนึ่งไปอีกห้องหนึ่ง แตะเพื่อวัด แล้วดูแผนที่สีที่แสดงประสิทธิภาพ Wi-Fi จริงของคุณค่อยๆ สร้างขึ้นเอง ทั้งความเร็วและค่าหน่วงเวลา (latency) ในจุดที่คุณใช้ชีวิตอยู่จริง
ไม่มีการสมัครสมาชิก ไม่มีโฆษณา ไม่ต้องสร้างบัญชี ซื้อครั้งเดียว เป็นของคุณตลอดไป

สิ่งที่คุณจะรู้ได้จริง
- ห้องไหนช้า และช้าแค่ไหน เป็นตัวเลขที่นำไปแก้ปัญหาได้จริง
- ปัญหาอยู่ที่ Wi-Fi หรืออยู่ที่อินเทอร์เน็ตของคุณ
- ควรวางโหนด Mesh ตัวขยายสัญญาณ หรือตัวเราเตอร์เองไว้ตรงไหน
- อุปกรณ์เครื่องไหนในเครือข่ายที่กำลังกินแบนด์วิดท์ของคุณ
- อุปกรณ์ IoT แต่ละเครื่องในเครือข่ายกำลังประกาศข้อมูลอะไรเกี่ยวกับตัวเองบ้าง

วิธีการทำงาน
1. เลือกแปลนห้องสำเร็จรูป หรือใช้รูปถ่ายแปลนของคุณเอง
2. เดินไปยังจุดที่ต้องการ แตะครั้งเดียว แอปจะวัดปริมาณงาน (throughput) และค่าหน่วงเวลา ณ จุดนั้น
3. ทำซ้ำในทุกห้อง ฮีตแมปจะค่อยๆ สร้างขึ้นระหว่างที่คุณเดิน
4. บันทึกแผนที่ที่เสร็จแล้วลงในรูปภาพ เพื่อเปรียบเทียบหลังย้ายตำแหน่งเราเตอร์

โหมดทีละขั้นตอนตั้งค่าทุกอย่างให้คุณ ไม่ต้องเลือกเป้าหมาย ไม่ต้องตั้งค่าโปรโตคอล ไม่ต้องอ่านคู่มือ และยังมีอินเทอร์เฟซขั้นสูงไว้ให้เมื่อคุณต้องการควบคุมทุกอย่างเอง

ไม่ต้องใช้ฮาร์ดแวร์เสริม ไม่มีการสมัครสมาชิก
การสำรวจ Wi-Fi ระดับมืออาชีพต้องใช้ Ekahau Sidekick หรือ WLAN Pi แต่แอปนี้ใช้แค่ iPhone ของคุณ และต่างจากแอปวิเคราะห์ Wi-Fi แทบทุกแอปใน App Store ตรงที่ไม่มีแพ็กเกจรายสัปดาห์ ไม่มีแพ็กเกจรายปี และไม่มีโฆษณา ซื้อครั้งเดียวจบ

เป็นชุดเครื่องมือเครือข่ายครบครันด้วย
- สแกนทุกอุปกรณ์ใน LAN พร้อมผู้ผลิต ที่อยู่ IP และพอร์ตที่เปิดอยู่
- ค้นหาบริการ mDNS/Bonjour ทั้งหมด: HomePod, Apple TV, เครื่องพิมพ์, อุปกรณ์ IoT
- Ping และวัดค่าหน่วงเวลาไปยังอุปกรณ์ในเครือข่ายและโฮสต์ใดก็ได้บนอินเทอร์เน็ต
- วัดปริมาณงานกับอุปกรณ์อื่นที่ใช้แอปนี้ เซิร์ฟเวอร์ TCP CHARGEN/DISCARD ใดก็ได้ หรืออินเทอร์เน็ต
- เปิดบริการ TCP CHARGEN หรือ DISCARD บนอุปกรณ์ของคุณเอง
- มุมมองโทโพโลยีเครือข่ายภายในแบบ 3 มิติพร้อมภาพเคลื่อนไหว

มาพร้อมไคลเอนต์ SNMP เต็มรูปแบบ
สืบค้นข้อมูลจาก SNMP agent ใดก็ได้บนเราเตอร์ สวิตช์ แอคเซสพอยต์ และเครื่องพิมพ์ รองรับ SNMP v1, v2c และ v3 พร้อม noAuthNoPriv, authNoPriv และ authPriv การยืนยันตัวตนแบบ MD5 และ SHA1 การเข้ารหัสแบบ DES และ AES มี MIB มาตรฐาน 64 รายการในตัว จึงแปลงตัวระบุออบเจ็กต์ (OID) เป็นชื่อที่อ่านเข้าใจได้แบบออฟไลน์ ไม่ต้องใช้เซิร์ฟเวอร์ ไม่ต้องสมัครสมาชิก ไม่ต้องตั้งค่าอะไรนอกจากที่อยู่ของ agent และข้อมูลยืนยันตัวตน

สำหรับบ้านและมืออาชีพ
พัฒนาโดยวิศวกรเครือข่าย ใช้ง่ายพอที่จะตรวจเช็กคอนโดของคุณได้ในบ่ายวันอาทิตย์ และแม่นยำพอที่มืออาชีพด้านโทรคมนาคมใช้ในการทำงานจริง

ก่อนซื้อ: สิ่งที่แอปนี้ทำไม่ได้
Apple ไม่อนุญาตให้แอป iOS ของบุคคลที่สามอ่านค่าความแรงสัญญาณ Wi-Fi หรือสแกนเครือข่ายรอบข้าง และไม่มีแอปใดใน App Store ทำได้ นี่คือเหตุผลที่เครื่องมือระดับมืออาชีพต้องใช้ฮาร์ดแวร์ภายนอก แอปนี้สร้างแผนที่จากสิ่งที่วัดได้ ณ จุดที่คุณยืนอยู่ นั่นคือปริมาณงานและค่าหน่วงเวลาจริง ซึ่งเป็นสิ่งที่ฮีตแมปในบ้านต้องการ แอปจะวัดเครือข่ายที่คุณเชื่อมต่ออยู่ และสร้างฮีตแมปทีละแผนที่
